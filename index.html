✅ 방법 1 (가장 쉬움): 아래 버튼을 눌러 수식 표를 복사한 뒤, 새 구글 시트 A1 칸에 붙여넣고 시트 주소만 연결하세요!

1. 위 [📋 내 종목 GOOGLEFINANCE() 수식 표 복사하기]를 누르고 구글 시트(https://sheets.new)의 A1 셀에 붙여넣기(Ctrl+V)하면 =GOOGLEFINANCE("KRX:005930", "price") 수식이 자동으로 계산됩니다.

2. 구글 시트 상단 메뉴 [파일 > 공유 > 웹에 게시]에서 전체 문서 + 쉼표로 구분된 값(.csv)으로 게시하거나, 우측 상단 [공유 > 링크가 있는 모든 사용자에게 공개] 후 주소를 복사해 아래 3단계 입력칸에 붙여넣고 저장하세요.

💡 팁: 한국 주식은 KRX:005930(또는 005930 입력 시 자동 변환), 미국 주식은 NASDAQ:AAPL, NYSE:TSLA 형식을 지원합니다.

✅ 방법 2 (Apps Script 웹앱 방식 - 시트에 종목을 미리 적어두지 않아도 실시간 계산):

구글 시트 상단 [확장 프로그램 > Apps Script]에 아래 코드를 붙여넣고 [배포 > 새 배포 > 웹 앱(모든 사용자 접근)] URL을 3단계 칸에 넣으면 어떤 종목이든 즉시 GOOGLEFINANCE()로 조회합니다.

function doGet(e) {
  var ticker = (e && e.parameter && e.parameter.ticker) ? e.parameter.ticker.trim() : "";
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  if (ticker) {
    // 6자리 숫자 코드면 KRX: 자동 부착
    if (/^\d{1,5}$/.test(ticker)) ticker = ("000000" + ticker).slice(-6);
    if (/^\d{6}$/.test(ticker)) ticker = "KRX:" + ticker;
    var cell = sheet.getRange("Z1");
    cell.setFormula('=GOOGLEFINANCE("' + ticker + '", "price")');
    SpreadsheetApp.flush();
    var price = cell.getValue();
    return ContentService.createTextOutput(JSON.stringify({ ticker: ticker, price: Number(price) }))
      .setMimeType(ContentService.MimeType.JSON);
  }
  // 파라미터가 없으면 시트 A~C열 전체 반환
  var rows = sheet.getDataRange().getValues();
  return ContentService.createTextOutput(JSON.stringify({ rows: rows }))
    .setMimeType(ContentService.MimeType.JSON);
}

[기존 테이블에 현재가(current_price) 및 티커(stock_code) 컬럼 추가 시] SQL Editor에서 실행:

alter table public.portfolios add column if not exists current_price numeric;
alter table public.portfolios add column if not exists stock_code text;

[처음부터 테이블을 새로 만들 때] SQL Editor에서 실행:

create table if not exists public.portfolios (
  id uuid primary key default gen_random_uuid(),
  user_id uuid references auth.users(id) on delete cascade not null,
  buy_date date not null,
  sector text not null,
  stock_code text,
  stock_name text not null,
  buy_price numeric not null,
  current_price numeric,
  quantity numeric not null,
  created_at timestamptz default now()
);

alter table public.portfolios enable row level security;

create policy "Users can manage own portfolio"
  on public.portfolios for all
  using (auth.uid() = user_id)
  with check (auth.uid() = user_id);

alter publication supabase_realtime add table public.portfolios;
